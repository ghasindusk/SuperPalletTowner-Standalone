# Third-party dependencies and asset provenance

This add-on interoperates with Cobblemon and NeoOrigins. It requires those mods but does not bundle their Jars, source code, Pokémon models, or item textures.

The Origin icon is the mod's own `super_pallet_towner:trainer_emblem` item. Its texture and the mod logo are original pixel art made for this project.

The Origin layer resource contains a compatibility snapshot of the NeoOrigins 2.2.29 `neoorigins:origin` layer, with the `neoorigins:monster_tamer` ID replaced by `starlight:super_pallet_towner`. NeoOrigins is MIT licensed; its origin-layer structure is credited here. The GUI panel is original artwork made for this project and contains no third-party assets.

Project pages: [Cobblemon](https://modrinth.com/mod/cobblemon), [Neo Origins](https://modrinth.com/mod/neo-origins).
