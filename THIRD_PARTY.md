# Third-party dependencies and asset provenance

This add-on interoperates with Cobblemon, NeoOrigins, and Cobblemon: Mega Showdown. It requires those mods but does not bundle their Jars, source code, Pokémon models, or item textures.

The Origin icon references `mega_showdown:ash_cap` by item ID. The cap model and texture remain in the separately installed Mega Showdown mod.

The Origin layer resource contains a compatibility snapshot of the NeoOrigins 2.2.29 `neoorigins:origin` layer, with the `neoorigins:monster_tamer` ID replaced by `starlight:super_pallet_towner`. NeoOrigins is MIT licensed; its origin-layer structure is credited here. The included GUI panel was generated from the project's original art script (`art/generate_affinity_device.py` in the private development project), which identifies it as original artwork without third-party assets.

Project pages: [Cobblemon](https://modrinth.com/mod/cobblemon), [Neo Origins](https://modrinth.com/mod/neo-origins), [Cobblemon: Mega Showdown](https://modrinth.com/mod/cobblemon-mega-showdown).
